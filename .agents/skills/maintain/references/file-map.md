## ANTLR grammar files (Phase 3 only)

| Path | Role |
|---|---|
| `src/main/antlr/*.g4` | Flattened copies from antlr/grammars-v4 |
| `src/main/java/*Base.java` | Hand-copied Java support classes from grammars-v4 `Java/` folders |
| `src/main/java/{CPP14,CSharp,Kotlin,Python,UnicodeClasses}*` | Regenerated by `generateGrammarSource` |
| `build.gradle.kts` `tasks.generateGrammarSource` | Enable only while regenerating; leave `enabled = false` |

Do not touch those paths during dependency or JDK-only work.

## Do not touch

- `code_blocks`, `clone_pairs` — generated runtime output, keep untracked

## Lookup sources

- Gradle plugins: https://plugins.gradle.org (`org.jetbrains.kotlin.jvm`, `com.gradleup.shadow`)
- Libraries: Maven Central (`rxkotlin`, `logback-classic`, `org.eclipse.jdt.core`, `antlr4`)
- Gradle wrapper: https://gradle.org/releases/
- Java LTS: current LTS as of the 2026-09 session is **25**. Confirm before bumping past 25.
- Shadow: plugin id is `com.gradleup.shadow` (Gradleup fork). `com.github.johnrengelman.shadow` is retired.
- ANTLR grammars: https://github.com/antlr/grammars-v4 (see `grammars.md` for lineages)
